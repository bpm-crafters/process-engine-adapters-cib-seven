## Usage

If you want to start usage, please add the BOM to your Maven project and add corresponding adapter implementation:

```xml
<dependency>
  <groupId>dev.bpm-crafters.process-engine-adapters</groupId>
  <artifactId>process-engine-adapter-cib-seven-bom</artifactId>
  <version>${process-engine-adapter-cib-seven.version}</version>
  <scope>import</scope>
  <type>pom</type>
</dependency>
```
